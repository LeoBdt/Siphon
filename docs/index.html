Siphon
Features Install GitHub

Your media, on your own machine.

Siphon is a web interface for yt-dlp. Paste a URL, choose a quality, and watch it arrive in a library you actually browse. Nothing leaves your machine.

Get started View source

What it does

The parts of a downloader you end up needing, rather than a wrapper around a command line.

Quality you choose

Video with sound up to 4K and 60 fps, or audio on its own. M4A and Opus are lifted straight from the source with no re-encoding, so nothing is lost; MP3 is there when you need compatibility.

Playlists and channels

Paste a playlist and pick which titles you want. Each becomes its own tracked job, grouped under a parent so one failure never hides in a crowd.

Progress as it happens

Speed, time remaining and the current stage — video, audio, merge, convert — pushed over a WebSocket. No polling, no guessing whether it is still alive.

A real library

Browse, rename, drag between folders, select with Ctrl or a rectangle, download a folder as a ZIP. Every operation is confined to one root directory.

Plays in place

A persistent audio bar that survives navigation, and a video player with fullscreen. The volume you set is remembered across both.

Keeps itself tidy

Disk usage at a glance, one-click yt-dlp updates, and a sweep for the leftovers an interrupted download leaves behind. English and French, switchable at runtime.

Run it

Two ways in. Docker is the short one — the images already carry yt-dlp and ffmpeg.

With Docker

The library and its database live in a volume mounted at /data, outside the containers. 

git clone https://github.com/LeoBdt/Siphon.git
cd Siphon
docker compose up -d --build

From source

Needs Node 20 or newer, plus yt-dlp and ffmpeg on your PATH. 

corepack enable
pnpm install
cp apps/api/.env.example apps/api/.env
pnpm dev

The app is then on http://localhost:3000.

Before you expose it

Siphon has no authentication yet. It runs processes and reaches the file system, so it belongs on a private network or behind protection at your reverse proxy — not on the open internet as it stands.

It is a personal tool for archiving and offline playback. What you may download is governed by each platform's terms and by copyright law where you live; making sure your use is lawful is your call.
